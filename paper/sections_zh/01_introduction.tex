\section{引言}

循证医学问答要求系统在生成或选择答案之前检索到相关的生物医学证据。检索增强生成（RAG）为结合检索证据与语言模型提供了通用框架 \citep{lewis2020rag}，近期医学 RAG 基准研究也表明，检索组件选择会显著影响医学问答效果 \citep{xiong2024benchmarking}。然而，常规词法检索或稠密检索通常只建模问题与段落之间的成对相似度。生物医学证据常常由问题、段落、MeSH 概念、生物医学实体、文档和关系来源之间的高阶关系共同组织。

本文研究的是一个实践性、领域特定的证据选择模块，而不是新的通用 RAG 范式。我们提出 KCH-MedRank：一种知识约束学习排序框架，可作为生物医学 RAG 的白盒证据选择模块。该方法使用 BM25、稠密检索和倒数排名融合保持候选生成的可复现性 \citep{robertson2009bm25,cormack2009rrf}，随后联合检索、生物医学语义、受控词表、实体、关系和局部结构特征。局部超图被用作抽取可解释高阶结构信号的一种架构变体；扁平医学知识特征模型和成对图分解作为受控基线。

本文贡献是一个聚焦的证据重排序框架，并附带事后特征归因分析。KCH-MedRank 结合生物医学语义检索分数、MeSH 层级感知特征、实体与关系特征、局部图或超图扩散与中心性特征，以及查询分组 LambdaMART 排序，以提升证据检索效果并暴露重排序所使用的证据信号。结构信号作为排序特征使用，而不是作为手工调权的独立公式。该系统不声称替代临床判断，不提供临床诊断，也不保证答案绝对正确。

实验使用公开生物医学问答资源，并强调证据检索指标、消融实验和受控支持分析。在 BioASQ 证据检索设置中，增强候选生成提高了留出测试集 top-100 召回上限，KCH-MedRank 相对于原始 Hybrid RRF 和真实 MedCPT Cross-Encoder 基线提升了 top-10 证据检索效果。关键消融显示，不含图结构的扁平医学知识 LTR 基线已与完整模型非常接近，因此主要性能主张应归因于组合式知识约束学习排序框架，而不是单独归因于超图拓扑。医学知识约束仍然重要：将其加入局部超图后，可以逆转无医学知识超图变体的退化，并带来统计显著的 top-10 提升。超图架构相对于成对图分解主要在 $k{=}5$ 提供适度额外收益；$k{=}10$ 时差异未达到统计显著。PubMedQA 与 BEIR NFCorpus 被用作次要诊断设置：PubMedQA 检查不同 QA 形式下的证据覆盖，NFCorpus 检查官方 BEIR 生物医学划分上的检索特征重排序稳健性，固定 prompt 的 Qwen3-8B pilot 则保留为附录式检查，而非主结果。

本文贡献包括：
\begin{itemize}
  \item 构建可复现的两阶段生物医学证据检索流水线，包含 BM25、稠密检索、Hybrid RRF、增强候选融合和留出测试评估；
  \item 设计扁平、成对图和局部超图变体，连接问题、段落、文档、实体、MeSH 概念、层级结构和辅助关系信号；
  \item 在查询分组条件下训练学习排序重排序器，联合利用检索、生物医学语义、MeSH 层级、实体、关系和超图特征；
  \item 通过结构消融框架证明扁平医学知识特征解释了大部分收益，医学知识约束对于避免图结构退化为噪声是必要的，超图在特定问题类型中提供适度的早期排序增益；
  \item 进行面向证据的评估，包括 Recall@k、Hit@k、MRR@k、nDCG@k、困难重排序子集、配对 bootstrap 显著性检验、失败分析、外部 retrieval-only 诊断和受控 PubMedQA Qwen3-8B 附录 pilot。
\end{itemize}

失败分析也显示存在丢失的金标准证据，因此本文将该方法表述为具有明确净收益和清晰失败模式的证据检索改进，而不是临床医学问答的完整解决方案。
