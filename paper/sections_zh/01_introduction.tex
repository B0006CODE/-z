\section{引言}

循证医学问答要求系统在生成或选择答案之前检索到相关的生物医学证据。检索增强生成（RAG）为结合检索证据与语言模型提供了通用框架 \citep{lewis2020rag}，近期医学 RAG 基准研究也表明，检索组件选择会显著影响医学问答效果 \citep{xiong2024benchmarking}。然而，常规词法检索或稠密检索通常只建模问题与段落之间的成对相似度。生物医学证据常常由问题、段落、MeSH 概念、生物医学实体、文档和关系来源之间的高阶关系共同组织。

本文研究的是一个实践性、领域特定的证据控制层，而不是新的通用 RAG 范式。我们提出 KCH-MedRank：一种知识约束的局部超图学习排序框架，可作为生物医学 RAG 的白盒证据选择模块。该方法使用 BM25、稠密检索和倒数排名融合保持候选生成的可复现性 \citep{robertson2009bm25,cormack2009rrf}，随后围绕每个问题及其候选证据段落构建局部跨粒度超图。

本文贡献是一个聚焦且可解释的证据重排序框架。KCH-MedRank 结合生物医学语义重排序分数、MeSH 层级感知特征、局部超图扩散与中心性特征，以及查询分组 LambdaMART 排序，以提升证据检索效果并暴露重排序所使用的证据信号。超图信号作为可解释排序特征使用，而不是作为手工调权的独立公式。该系统不声称替代临床判断，不提供临床诊断，也不保证答案绝对正确。

实验使用公开生物医学问答资源，并强调证据检索指标、消融实验和受控支持分析。在 BioASQ 证据检索设置中，增强候选生成提高了留出测试集 top-100 召回上限，KCH-MedRank 相对于原始 Hybrid RRF 和真实 MedCPT Cross-Encoder 基线提升了 top-10 证据检索效果。PubMedQA 被用作次要诊断设置：检索实验检验证据覆盖的迁移性，固定 prompt 的 Qwen3-8B pilot 检查证据选择是否影响下游答案准确率和支持行为。

本文贡献包括：
\begin{itemize}
  \item 构建可复现的两阶段生物医学证据检索流水线，包含 BM25、稠密检索、Hybrid RRF、增强候选融合和留出测试评估；
  \item 设计局部知识约束超图表示，连接问题、段落、文档、实体、MeSH 概念、层级结构和辅助关系信号；
  \item 在查询分组条件下训练学习排序重排序器，联合利用检索、生物医学语义、MeSH 层级、实体、关系和超图特征；
  \item 进行面向证据的评估，包括 Recall@k、Hit@k、MRR@k、nDCG@k、困难重排序子集、配对 bootstrap 显著性检验、消融实验、失败分析和受控 PubMedQA Qwen3-8B 生成 pilot。
\end{itemize}

失败分析也显示存在丢失的金标准证据，因此本文将该方法表述为具有明确净收益和清晰失败模式的证据检索改进，而不是临床医学问答的完整解决方案。
