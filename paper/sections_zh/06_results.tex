\section{实验结果}

\subsection{候选池质量}

表~\ref{tab:enhanced-bioasq-main-results} 总结了 BioASQ 留出测试集主结果。原始 Hybrid RRF 测试基线的 Recall@10 为 0.4636，MRR@10 为 0.7550，nDCG@10 为 0.5848，Recall@100 为 0.6077。增强 w122 候选池根据验证集 Recall@100 选择，并在测试集达到 Recall@100 = 0.7388，为重排序提供了更强的候选上限。这一步很重要，因为如果金标准证据没有进入候选池，后续重排序无法恢复该证据。

\subsection{留出测试集主结果}

Enhanced KCH-MedRank 达到 Recall@10 = 0.5332、MRR@10 = 0.7882、nDCG@10 = 0.6446、Recall@100 = 0.7388。相对于原始 Hybrid RRF，这对应 Recall@10 +0.0696、MRR@10 +0.0332、nDCG@10 +0.0598 的提升。相对于增强 Hybrid RRF 的候选排序，KCH-MedRank 的 Recall@10 提升 +0.0673，MRR@10 提升 +0.0352，nDCG@10 提升 +0.0602，evidence coverage@10 提升 +0.0673。

表~\ref{tab:enhanced-bioasq-bootstrap-hybrid} 报告了相对于增强 Hybrid RRF 的成对 bootstrap 检验。四个 top-10 指标均达到显著，$p=0.0002$。这说明提升并不只是来自更强候选池，重排序步骤本身也显著改变了 top-10 证据排序。

\subsection{与生物医学语义重排序的比较}

在同一增强候选池上，真实 MedCPT Cross-Encoder 基线达到 Recall@10 = 0.5172、MRR@10 = 0.7775、nDCG@10 = 0.6390。表~\ref{tab:enhanced-bioasq-significance} 报告了相对于该强语义基线的成对 bootstrap 结果。KCH-MedRank 在 Recall@10 上显著提升（$p=0.0074$），MRR@10 和 nDCG@10 为正向提升但未达到统计显著。

\input{tables/enhanced_bioasq_significance_zh}

与 MedCPT Cross-Encoder 的比较是对所提出重排序器更严格的检验。结果表明，KCH-MedRank 能在强生物医学语义重排序器之外进一步提高 top-10 证据覆盖，但 MRR 和 nDCG 的排序敏感指标只能表述为正向趋势，而不是显著提升。这些结果支持本文的证据检索主张，但尚不足以把答案生成作为主要贡献。

\subsection{Hard Reranking 与 PubMedQA 诊断}

表~\ref{tab:hard-subset-diagnostic} 报告了 hard subset 诊断结果。该子集包含增强 Hybrid top-100 中存在金标准证据、但增强 Hybrid top-10 未命中的 BioASQ 留出测试问题，共 65 个问题。该子集只用于诊断分析，不能替代完整测试集评估。在该子集上，增强 Hybrid RRF 的 Recall@10 按定义为 0，而完整 KCH-MedRank 达到 Recall@10 = 0.4751。这说明当候选池中存在可恢复金标准证据时，重排序器能够将相当一部分遗漏证据提升到 top-10。该子集也再次显示了消融中的整体趋势：检索和语义特征解释了很大一部分恢复效果，超图和医学知识特征更应解释为互补信号，而不是单独解释全部提升。

\input{tables/hard_subset_diagnostic_zh}

表~\ref{tab:pubmedqa-retrieval-diagnostic} 给出了 PubMedQA 上的次要检索诊断。PubMedQA 的证据结构与 BioASQ 不同，且一位命中表现已经很强，因此本文仅将其作为稳健性检查。轻量 HGB 知识重排序器相对于其 Hybrid RRF 来源将 Recall@10 从 0.8200 提高到 0.8953；实验日志中的成对 bootstrap 显示 Recall@10 差值为 +0.0754，$p=0.0002$。MRR@10 仅从 0.9850 变化到 0.9861，且不显著，这与 PubMedQA 已经具有较高一位命中的特点一致。因此，该结果支持证据覆盖改善的解释，而不是泛化为答案生成能力的全面提升。

\subsection{答案支持分析}

PubMedQA 答案选择分析进一步区分了证据检索与答案正确性。对于 Hybrid 和 HGB 的 top 10 证据，规则化引用支持率均为 1.0000，因为每个评估问题都至少检索到一个金标准证据段落。然而，答案支持率仍受轻量 yes/no/maybe 答案选择器限制：多数类基线的支持答案比例为 0.5550，而 TF-IDF 逻辑回归在 Hybrid 与 HGB top 10 上分别为 0.5050 和 0.4800。在 98 个抽取到问题实体的问题中，top 10 答案-证据实体一致性为 0.5510。这些分析使用 qrels、金标准标签和确定性实体重叠，而不是 LLM 评审。因此，在加入更强答案与忠实性建模前，答案生成仍应作为次要任务。

表~\ref{tab:pubmedqa-qwen-pilot} 报告受控 Qwen3-8B pilot。在 100 个 PubMedQA 问题上，相对于 Hybrid RRF 证据，KCH 风格超图证据在相同 prompt 和解码设置下将答案准确率从 0.3400 提高到 0.3700，将 Macro-F1 从 0.3506 提高到 0.3760。三个证据来源的引用支持率均为 0.9900，因此该 pilot 未显示引用支持差异；主要结论是证据排序可能影响下游标签选择。由于 PubMedQA cross-encoder 条件使用的是当前可用的语义 cross-encoder 输出，而不是已完成的 MedCPT PubMedQA 复现实验，该结果被报告为诊断性 RAG 闭环，而不是完整第二数据集主张。
