\section{消融实验}

消融实验用于区分检索强度、生物医学语义、医学知识约束和超图结构的贡献。评估变体分别移除生物医学语义分数、MeSH 层级特征、生物医学实体特征、超图扩散与中心性、PrimeKG 关系特征。所有变体使用同一增强 top-100 候选池，因此差异反映重排序行为，而不是候选可用性。

本文对消融结果保持克制解释。生物医学语义和检索特征很强。MeSH 层级和共享概念簇提供了具有医学可解释性的特征，但部分 leave-one-out 消融差异较小或呈混合趋势。PrimeKG 精确名称关系特征覆盖较低，除非后续概念归一化显著提升其贡献，否则应保持辅助定位。

消融表显示四点。第一，仅使用检索特征进行学习排序已经相对于增强 Hybrid RRF 带来较强提升，Recall@10 从 0.4660 提高到 0.5208。这说明监督式查询分组排序目标本身是方法的重要组成部分。第二，加入生物医学语义证据后，最强重排序变体进一步改善；不含超图但包含语义特征的模型达到 Recall@10 = 0.5328、MRR@10 = 0.7885。

第三，图结构和医学约束更适合解释为互补特征。成对图 LTR 与完整 KCH-MedRank 表现接近，而不含医学知识的超图变体在 Recall@10 和 MRR@10 上弱于完整模型。这支持使用医学约束，但不应声称单靠超边结构主导提升。第四，PrimeKG 在该实现中不是主要驱动因素。移除 PrimeKG 关系特征后模型仍有 Recall@10 = 0.5252、MRR@10 = 0.7834，这与精确名称关系匹配覆盖稀疏的观察一致。

表~\ref{tab:strong-ablation-significance} 进一步给出相对于强消融变体的成对 bootstrap 检验。完整 KCH-MedRank 在 Recall@10 和 nDCG@10 上显著优于成对图 LTR，但相对于 LambdaMART + 语义且无超图、移除 MeSH 层级、移除超图扩散/中心性的差异均未达到统计显著。该结果收窄了可支持的主张：局部超图和医学知识特征提升了解释性并提供有用信号，但当前证据不能证明任何单一特征组主导排序收益。

\subsection{超图与对偶图的分层分析}

为理解超图 $n$-元超边何时优于对偶图的成对分解，我们按问题结构特征对测试集进行分层 bootstrap 比较。表~\ref{tab:hypergraph-vs-pairwise-stratified} 展示了 Recall@5 和 Recall@10 的分层结果。

\input{tables/hypergraph_vs_pairwise_stratified}

分层分析揭示两个关键模式。首先，当金标准段落与问题\textbf{无直接 MeSH 重叠}时，超图优势最大（Recall@5 $\Delta=+0.0098$，$p=0.006$）。这具有结构解释性：当存在直接 MeSH 重叠时，对偶图分解已经通过共享概念边捕获了大部分对齐信号；当不存在时，超图的 $n$-元结构通过共享实体簇和 MeSH 层级祖先提供间接路径，这些路径在对偶图分解中被碎片化。其次，具有 $\geq 2$ 个金标准段落的问题同样显著受益于超图（Recall@5 $\Delta=+0.0042$，$p=0.023$），这与多证据场景中超图的共享实体超边跨金标准段落传播排序信号的设计一致。

在 $k=10$ 时，无子集达到统计显著，但效应方向一致（除一个子集外 $\Delta$ 均为正）。单一金标准段落子集具有最大名义 $\Delta$（+0.0098），但由于样本量较小（$n=204$）统计功效不足。这确认了超图优势集中于早期排序区域以及需要间接知识信号补充缺失直接概念对齐的场景。
