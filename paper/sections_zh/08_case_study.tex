\section{可解释性与案例分析}
\label{sec:interpretability}

KCH-MedRank 的一个核心方法论声明是其基于超图的重排序是\textbf{可解释的}：每一例金标准段落的救回都可以追溯到超图中的具体知识约束机制。本节提供量化证据支持该声明。

\subsection{救回案例的三机制分类}

我们将 KCH-MedRank 从 Hybrid RRF top-10 之外救回 top-10 以内的全部 648 个金标准段落按主导超图机制分类：

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{MeSH 层级路径}：问题与金标准段落通过 MeSH 树形祖先路径共享概念。例如关于``DITPA''的问题与关于``thyroid hormones''的段落通过共享 MeSH 词``thyroid hormones''及其树形祖先相连接。
    \item \textbf{共享实体簇路径}：金标准段落与其他候选段落共享生物医学实体，形成共享实体超边簇，通过扩散传播排序信号。
    \item \textbf{PrimeKG 关系路径}：问题实体通过 PrimeKG 生物医学关系与段落实体相连（如``Dasatinib --治疗-- 白血病''）。
\end{enumerate}

\input{tables/interpretability_mechanisms}

表~\ref{tab:interpretability-mechanisms} 展示了分类结果。MeSH 层级路径是最主要的可解释机制，占救回案例的 75.9\%，平均排名提升 +22.1 位。共享实体簇路径占 23.9\%，平均提升 +14.0 位。PrimeKG 关系路径频率最低（0.2\%），这与结构化生物医学知识图谱关系的稀疏性一致——相比所有 PubMed 文献均有 MeSH 标注的覆盖密度。

表~\ref{tab:mech-cooccurrence} 显示 89.2\% 的救回案例涉及至少两种知识路径的协同激活，39.5\% 同时激活全部三种机制。这确认了 KCH-MedRank 中的医学知识约束作为一个整体模块发挥作用，与结构消融中移除整个知识模块导致超图退化为噪声的发现一致。

\subsection{可解释性量化总结}

三机制分析表明 KCH-MedRank 排序决策中激活的超图特征遵循可解释的知识约束路径：

\begin{itemize}
    \item 100\% 的救回段落显示至少一种知识特征的激活（零例纯扩散驱动），基于我们启发式的主导机制分类。
    \item MeSH 层级路径是 75.9\% 救回案例中最频繁激活的主导通路，说明分层 MeSH 树结构携带最强的知识信号。
    \item 89.2\% 的救回涉及多种知识路径的协同激活，确认了知识约束的互补性。
    \item MeSH 驱动救回的平均排名提升（+22.1）显著大于实体驱动（+14.0），表明层级概念对齐比扁平实体共现提供更强的排序信号。
    \item \textbf{局限性}：机制分类使用了 LambdaMART 排序器消费的同一组特征分数；它识别哪些知识特征最强烈激活，而非哪些特征因果驱动排序。未来的工作可结合模型无关归因方法（如 SHAP）增强因果可解释性声明。
\end{itemize}
