\subsection{结构消融：每个组件贡献了什么？}
\label{sec:ablation}

本次消融比较的是架构而非特征子集。知识特征之间的高多重共线性意味着移除单组特征时 LambdaMART 会自动用剩余相关组补偿，因此留一消融不具有信息量，见附录。我们改为比较五个受控架构变体，每个回答一个特定的结构问题。

\input{tables/structural_ablation}

扁平生物医学知识特征能否在检索之上产生改进？能。将预计算生物医学语义分数、实体特征、层级感知 MeSH 特征和 PrimeKG 关系特征加入仅检索 LTR 模型，Recall@10 从 0.5208 升至 0.5309（$\Delta{=}+0.0101$，$p{=}0.0006$），nDCG@10 从 0.6282 升至 0.6436（$\Delta{=}+0.0153$，$p{=}0.0002$）。生物医学知识特征自身，不加任何图结构，已经承担了聚合改进的很大一部分。仅告诉排序器共享 MeSH 概念和实体重叠就已经是强信号。

原始超图拓扑是有帮助还是有损害？有损害。无医学知识超图变体构建了完整的超图拓扑但剔除了所有 MeSH、实体和 PrimeKG 标注。结果跌至扁平知识基线以下：nDCG@10 下降 0.0074（$p{=}0.0002$），MRR@10 下降 0.0089（$p{=}0.003$）。原始图结构在缺少领域概念信息时会引入排序噪声。这是对通用 GraphRAG 流水线中"任何图结构都比没有好"这一隐含假设的经验否定。

医学知识约束能否逆转结构噪声？能。将生物医学实体特征、MeSH 层级特征和 PrimeKG 关系特征加入无医学知识超图后，Recall@10 提升 0.0063（$p{=}0.0028$），MRR@10 提升 0.0085（$p{=}0.0042$），nDCG@10 提升 0.0071（$p{=}0.0002$）。三项指标均达到显著。同一超图架构，在没有知识约束时损害排序，加入约束后变成有用的结构信号。领域约束是必需的，不是可选的。

完整模型在 $k{=}10$ 上是否优于扁平知识？否（Recall@10 $\Delta{=}+0.0020$，$p{=}0.254$；表~\ref{tab:structural-ablation-interpretation}）。超图在标准评估深度上不主导聚合排序。其角色是互补和可解释的。

\input{tables/structural_ablation_interpretation}

那么超图在哪里起作用？在早期排序位置。比较完整超图与成对分解在 $k{=}5$ 的表现，Recall@5 提升 0.0054（$p{=}0.003$），nDCG@5 提升 0.0037（$p{=}0.028$）。超图的高阶连接保留了成对分解会碎片化的间接知识路径。

超图最大收益落在金标准段落与问题无直接 MeSH 重叠的问题上（$\Delta_{\text{Recall@5}} = +0.0098$，$p=0.006$）。有直接 MeSH 重叠时，成对图已经能通过共享概念边捕获对齐信号。无直接重叠时，成对方法碎片化了经由共享实体簇和 MeSH 层级祖先的间接路径。超图原生地保留了这条路径。拥有两条及以上金标准段落的问题也受益（$\Delta_{\text{Recall@5}} = +0.0042$，$p=0.023$），与多证据场景中共享实体超边跨金标准段落传播信号一致。

总结消融结果：扁平生物医学知识特征承担了大部分聚合收益。原始超图拓扑在无医学标注时是有害的。医学知识约束将噪声逆转为信号。超图提供针对性的早期排序收益，集中于缺少直接 MeSH 重叠的问题。医学知识特征作为一个集成模块发挥作用，单个特征组高度冗余，是约束的组合才使结构变得有用。
