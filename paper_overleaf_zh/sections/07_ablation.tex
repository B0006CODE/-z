\subsection{消融实验}

本节将 KCH-MedRank 的性能分解为扁平生物医学知识特征、图结构、超图结构和医学知识约束的效应。如第 4 节所述，移除单个特征组的消融见附录作为补充诊断；主要证据来自受控架构比较，因为知识特征之间的高多重共线性会导致树模型自动补偿。

我们首先进行最直接的比较：扁平生物医学知识特征——不使用任何图或超图结构——已能解释检索信号之上的大部分增益。比较 (1) 表明，将预计算的生物医学语义分数、实体特征、精确与层级感知 MeSH 特征以及辅助 PrimeKG 关系特征加入仅检索特征的 LTR 模型，将 Recall@10 从 0.5208 提升至 0.5309（$\Delta{=}+0.0101$，$p{=}0.0006$），nDCG@10 从 0.6282 提升至 0.6436（$\Delta{=}+0.0153$，$p{=}0.0002$）。MRR@10 从 0.7791 提升至 0.7872（$p{=}0.029$）。仅扁平生物医学知识——检索分数、语义特征、MeSH、实体和关系——已捕获了总体改进的很大一部分。

扁平知识特征已经很强，因此下一比较检验超图在扁平特征之上还能贡献什么。比较 (2) 表明，在不含医学知识的情况下加入超图结构\textit{降低}了排序质量。无医学知识超图变体构建了完整的超图拓扑但剥离了 MeSH、实体和 PrimeKG 标注，结果低于扁平知识基线：nDCG@10 下降 0.0074（$p{=}0.0002$），MRR@10 下降 0.0089（$p{=}0.003$）。原始图拓扑不能替代领域概念信息；单独使用时，它引入结构噪声。

比较 (3) 检验了医学知识约束能否逆转原始结构引入的噪声。将生物医学实体特征、精确 MeSH 特征、MeSH 层级特征和 PrimeKG 关系特征加入无医学知识超图后，Recall@10 提升 0.0063（$p{=}0.0028$），MRR@10 提升 0.0085（$p{=}0.0042$），nDCG@10 提升 0.0071（$p{=}0.0002$）。三个 top-10 指标全部达到统计显著。医学知识约束将超图从噪声源转化为有用的结构信号。

\input{tables/structural_ablation_interpretation}

表~\ref{tab:structural-ablation-interpretation} 将这些发现放在上下文中。比较 (4) 显示完整模型在 $k{=}10$ 上并未显著优于扁平知识 LTR 基线（Recall@10 $\Delta{=}+0.0020$，$p{=}0.254$）。图和超图特征因此作为可解释的互补信号与主要扁平知识特征一起贡献；它们在本文报告的评估深度上并不独立主导总体排序。

超图真正有所区分的是在早期排序位置。比较 (5) 评估了 n 元超边相对于将多节点超边拆解为锚点成对边的成对分解的效果。在 $k{=}10$ 上差异不显著（Recall@10 $\Delta{=}+0.0023$，$p{=}0.203$）。但在 $k{=}5$ 上，Recall@5 提升 0.0054（$p{=}0.003$），nDCG@5 提升 0.0037（$p{=}0.028$）。超图的高阶连接性提供了成对分解——将多节点超边碎片化——无法完全复制的早期排序信号。

超图收益最大的是金标准段落与问题\textit{无直接 MeSH 重叠}的情形（$\Delta_{\text{Recall@5}} = +0.0098$，$p=0.006$）。当存在直接 MeSH 重叠时，成对图分解已通过共享概念边捕获了对齐信号。当不存在时，成对方法碎片化了间接路径——经由共享实体簇和 MeSH 层级祖先——而超图原生地保留了这些路径。具有 $\geq 2$ 个金标准段落的问题同样显著受益于超图（$\Delta_{\text{Recall@5}} = +0.0042$，$p=0.023$），与多证据场景中共享实体超边跨金标准段落传播信号的设计一致。在 $k{=}10$ 时，无子集达到显著但效应方向一致（除一个子集外 $\Delta$ 均为正）。

综上所述，扁平检索、生物医学语义和医学知识特征解释了相对于增强 Hybrid RRF 的大部分总体改进。没有医学概念标注的原始超图拓扑是有害的：单独使用结构会引入噪声。医学知识约束逆转了这一噪声并提供可解释的生物医学信号。超图在 $k{=}5$ 上提供针对性额外收益，其优势集中于问题与证据之间缺乏直接 MeSH 重叠的情形。附录中移除单个特征组的诊断显示各知识特征组之间高度冗余，确认了医学约束作为集成模块发挥作用的设计原则。
